## World Guard
Grab a wooden Axe to select Position 1 & Position 2 using Left and Right click on a block with the Axe in Hand.
You can also set a tool with the command `/farwand`<br>
You can then alter the selected Area using commands.<br> 
Set selected area to a certain block:<br>
`//set <block_name>`<br>
Expand the Selected area an amount and a direction:<br>
`//expand <#> <direction>`<br>
Used to Copy the Selected Area, Paste the Selected Area, or Rotate the currently Selected Area:<br>
`//Copy //Paste //Rotate`<br>
Makes walls of the selected block:<br>
`//Walls <block_name>`<br>
Replaces block_1 with block_2<br>
`//Replace <block_1> <block_2>`<br>
You can use commas to make combinations, this command will set the area 50% stone and 50% air<br>
`//set cobblestone,air`<br>
