[Citizens] Plugin
## Create Citizens
Create NPC:<br>
`/npc create <name>`<br>
NPC Select:<br>
`/npc select` (Looking at Target NPC)<br>
Add a click command:<br>
`/npc command add -p /warp shop`<br>
To have an NPC run a command when clicked<br>
`/npc rename <NewName>`<br>
Speak to Player Command:<br>
`/npc command add npc speak Hello, %player%, you can always access my menu with '/class attr' --target %player%`<br>
